## Experience

### 🏢 Kapture CX — Machine Learning Engineer
*March 2025 – Present · Bengaluru, India*

- Designed and deployed scalable AI-driven chatbots using **MCP servers** with customized agents for enterprise use cases; owned end-to-end deployment on **GCP VM instances**.
- Built a production **voicebot** system integrating **Voice Activity Detection (VAD)**, optimized TTS/STT synthesizer models, and onboarded multiple telephony vendors — scaling the platform to **50+ lakh calls**.
- Integrated **Gemini Live** into the voicebot pipeline for real-time, end-to-end voice interaction, improving scalability and latency.
- Built an automated **QA evaluation system** for AI agents, cutting manual evaluation effort by **~70%** and scaling assessment to **10K tickets/day**.
- Integrated **RAG-based retrieval** into chatbots and voicebots, adding **RAGAS** metrics (faithfulness, answer relevancy, context precision) to measure and improve response quality — reducing LLM invocation costs by **~35%**.
- Owned and maintained VM deployment for all product services, ensuring reliable releases across the team.
